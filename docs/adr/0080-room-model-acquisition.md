# ADR-0080：房间模型获取与模型库导入

状态：接受。日期：2026-10-07。

用户授权替代 ADR-0077 中“不下载、不导入远端资产”的限制。
本地导入模型通过独立可靠有序 WebRTC 模型通道传输；在线模型库来源携带
下载地址、标题和输入模式，由接收方 HTTPS 下载。内置模型继续直接复用。
下载和打包在独立 worker，键鼠边沿通道不承担模型数据或磁盘工作。

传输使用有限大小的分块、连续偏移和明确开始/结束，限制并发、总大小、
队列和超时：单包与同时接收的声明总量上限为 128 MiB，最多 32 个成员，
单块 1536 字节，空闲传输 30 秒取消。只分享当前活动模型目录，拒绝
符号链接和越界路径。来源地址仅接受现有模型库使用的 GitHub、
raw.githubusercontent.com 与 jsDelivr GitHub HTTPS zip 地址。
接收端复用限量解压和模型库事务导入，分配本机 UUID，不覆盖既有资产，
不改变用户当前模型选择。在线来源记录是可缺省字段，旧配置仍正常读取。
下载、连接、校验或导入失败保持默认猫；成员离开后的过期结果不得导入或显示。

模型保留在当前环境模型库。共享双方 UUID 可以不同，房间成员计划维护广告
身份到本机导入身份的映射。模型发送者自行承担其所分享内容的授权。

## Phase 5 退出条件

- [ ] 模型通道、来源记录、失败回退和模型库导入闭环：需自动化协议/路径/
  大小/旧配置回归，Windows 双客户端实测；macOS 与跨 NAT 网络验证仍独立验收。
- [ ] 断线、切换、重启、shutdown 清理和大模型压力验证；网络不支持直连时
  回退默认模型，TURN 部署另行验收。

## 当前证据

2026-10-07 Windows `just check`（格式化、全部静态检查、workspace 测试与
Release check）通过。自动化覆盖 P2P 包传输、导入后生成本机 UUID、房间显示、
保持自己的模型选择、来源持久化与重启读取；HTTPS 下载成功与 HTTP 失败，
越界偏移、队列上限、旧配置缺省字段、符号链接、路径越界与大小限制。
`just room-peer-smoke` 使用本机服务和真实 WebRTC 通道，4 项通过，包含
模型传输、键鼠释放、断线 Reset 和 worker shutdown；模型 worker 在 2 秒内退出。
`just room-window-smoke` 验证 Windows 两个成员窗口渲染和聊天路由，通过。

以上证据不替代 macOS、跨 NAT 网络、大模型压力与长时间运行验收；
Phase 5 checkbox 保持未完成。旧版下载模型没有来源记录，分享时使用 P2P；
新下载的模型记录来源，双方需要使用支持该协议的客户端。

## 成员反馈与缓存

成员窗口显示该成员的实际接收进度，未知总量显示活动条，解压/导入阶段显示满条；
完成或失败后隐藏。聊天文字使用字体的基线坐标，鼠标悬停显示用户名。
成功导入模型在 metadata 保留原始共享模型 ID；在线来源按 URL 与输入模式复用，
本地分享按共享 ID 与输入模式复用。缓存条目仅在模型仍存在时有效，失败不记缓存。
旧 metadata 缺少共享 ID 时正常读取。删除模型库条目会使缓存失效。

成员列表提供本机显示/隐藏控制；隐藏移除该成员窗口 owner，不移除缓存或房间成员，重新显示复用已准备的模型。状态仅对当前房间有效，退房或成员离开后清除。

成员反馈与缓存的 Windows 证据：`just check`、`just room-window-smoke` 与
`just room-peer-smoke` 通过，后两项分别覆盖带进度条的两个 D3D11 窗口及
4 个真实 WebRTC 双客户端场景。回归覆盖重启后按共享身份/URL 复用且
不发请求、不重复导入，隐藏/恢复按成员 ID 隔离并保留聊天，悬停与聊天
独立结束，未知总量活动条，以及中英文文字不越过气泡内边距。
已检查字体生成的渲染预览；macOS、Windows 多 DPI 实机交互和跨 NAT 验收
尚未运行，不作为已完成证据。
