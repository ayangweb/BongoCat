BongoCat は Windows と macOS 向けのデスクトップコンパニオンです。Live2D の猫が画面の上で暮らし、その目と前足はマウスを追いかけ、キー、マウスボタン、ゲームパッドのボタンを押すたびに反応します。好きな Live2D モデルを持ち込み、ウィンドウを好きな場所に動かせます。猫は、あなたが再び呼びたくなるまで邪魔をしません。

[MMmmmoko](https://github.com/MMmmmoko) 作の [Bongo-Cat-Mver](https://github.com/MMmmmoko/Bongo-Cat-Mver) に着想を得ています。

## 機能

- macOS と Windows で動作します。
- 押したキー、マウスボタン、ゲームパッドのボタンそれぞれに合った動きを再現します。
- 好きな Live2D モデルを持ち込んで、猫を自分だけのものにできます。
- 完全なオープンソースで、コードは公開されており、ユーザーデータの収集は行いません。
- ネットワークにアクセスせずオフラインで動作するため、プライバシーが守られます。

## その他のモデル

[Awesome-BongoCat](https://github.com/ayangweb/Awesome-BongoCat) では、さらに多くの猫モデルを閲覧・ダウンロードしたり、自作のモデルを共有したりできます。
